MILESTONE 7 — UPLOAD TO GITHUB

1. Extract NuLinkAndroid_Milestone7_HEX_Validation.zip.
2. Upload the CONTENTS of the extracted folder into the root of your existing GitHub repository.
3. Include the hidden .github/workflows/android.yml folder/file.
4. Commit changes. app/build.gradle.kts is versionCode 7 / versionName 0.7-hex-validation.
5. Open Actions -> Build Nu-Link Android APK.
6. Download the NuLink-Android-debug-APK artifact.

This milestone validates Intel HEX files and target APROM address ranges. It does NOT send flash erase/program/verify commands.
