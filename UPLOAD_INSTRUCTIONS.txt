MILESTONE 8 — GITHUB BUILD

1. Extract NuLinkAndroid_Milestone8_Protocol_Research.zip.
2. Open the extracted folder.
3. Upload its CONTENTS to the root of your existing GitHub repository.
4. Make sure the hidden .github/workflows/android.yml folder is included.
5. Commit the files.
6. Open GitHub -> Actions -> Build Nu-Link Android APK.
7. Download the NuLink-Android-debug-APK artifact.

This is a source package, not a precompiled APK.
APROM erase/program/verify are still disabled pending safe protocol validation.
