Nu-Link Android Milestone 5 (v0.5) — GitHub upload

1. Extract this ZIP.
2. Open the extracted NuLinkAndroid_Milestone5_Diagnostics folder.
3. In GitHub, open the existing repository, choose Add file > Upload files.
4. Upload the CONTENTS of this folder into the repository root (including the hidden .github folder).
5. Commit changes with message: Add Nu-Link auto-detect diagnostics v0.5
6. Open Actions and run “Build Nu-Link Android APK”.
7. Download artifact “NuLink-Android-debug-APK” from the completed run.

Do not upload the ZIP itself. Do not delete the repository. This project is a diagnostic capture-replay build only; it does not erase or program the target MCU.
